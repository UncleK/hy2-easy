---
name: hy2-easy
description: 用本机 hy2-easy 工具配置用户自己的 Hysteria 2 VPN，并返回客户端官方下载入口、二维码和导入链接。适用于具备本地 MCP 或终端执行能力的 Agent。
---

用户的目标是扫码或复制即可连接，尽量让工具完成技术步骤。

已接入 MCP 时：

1. 调用 `hy2_setup`，把返回的本机 `url` 作为可点击链接展示，告诉用户在页面填写服务器登录信息。SSH 密码、私钥不要作为工具参数或聊天消息索取。
2. 用户在页面确认服务器指纹并开始安装。用返回的 `id` 调用 `hy2_status`，约每 5 秒查询；等待填写时不必持续轮询。
3. `stage=done` 后调用 `hy2_connection`。展示原始二维码图片和完整连接链接，再展示 `hy2_downloads` 中适合用户设备的下载链接。支持图片由 Agent 宿主决定；不能显示时保留本机页面链接，那里可以扫码和复制。不要使用第三方图床、二维码网站或在线订阅转换器。
4. `verified=true` 才能说“已从当前电脑检测连接成功”；未通过时说明服务已安装，提醒检查对应 UDP 端口或导入客户端尝试。`error` 时按返回消息修复，不循环重装、不覆盖现有服务。

DSH 可能把工具加上 `mcp__hy2-easy__` 等前缀，按实际工具列表调用。
如果用户取消“聊天里显示”选项，尊重本机页面展示方式，不从其他途径读取连接凭据。
二维码和 URI 本身就是 VPN 凭据，展示到聊天中会进入宿主会话记录；SSH 凭据由本工具在内存中使用。具有同一操作系统用户权限的 Agent 不是独立的安全隔离区。

未接入 MCP，但可以执行本地命令时：先按项目 `docs/agent.md` 中的分发包步骤准备工具。也可运行 `node agent/src/standalone.mjs` 打开同一配置页面，在页面完成后读取连接链接与页面地址并展示给用户。不要另写 SSH 安装脚本。
不能执行本地工具的普通聊天产品无法自动配置服务器；说明缺少的能力，提供项目教程，不声称适配完成。

默认 Windows 提供 v2rayN，安卓提供 v2rayNG；苹果和 Mihomo 放在用户需要时介绍。
GitHub 官方下载优先；只有工具实际返回 `backup` 时才展示服务器备份。不要把海外服务器描述为国内源，也不要承诺未测网络能够直连。
本项目使用 Hysteria 2，简化的是部署和配置，不是自创协议。不能因开源或配置简单就承诺无风险。
