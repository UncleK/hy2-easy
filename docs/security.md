# 隐私与连接校验

hy2-easy 是可审查的部署脚本，不承诺“绝对无害”或匿名性。

## 数据去哪了

- 安装依赖时连接发行版软件源；下载代码与核心时连接 GitHub 及其文件分发域名。
- 密码、证书和二维码在服务器本地生成，没有二维码生成 API 或本项目的收集端点。
- 服务没有本项目的遥测、注册、广告或集中式订阅后台。
- 服务启动命令关闭上游核心的自动更新检查；官方客户端排错命令同样关闭此检查。
- 未认证请求收到本地静态 404，不转发到第三方伪装网站。
- 使用时的流量经你配置的 VPS 到达目标网站；VPS 提供商、目标网站和客户端软件各有自己的信任边界。
- systemd journal 保留本地服务诊断日志，默认 `warn` 级别。不要将完整日志和连接凭据直接贴到公开 Issue。

## 自签证书与指纹

每次新安装生成 256 位随机密码，以及独立的 P-256 自签证书（有效期 10 年）。
分享链接同时包含 `insecure=1` 与 `pinSHA256=<证书 SHA-256>`：
前者跳过公共 CA 信任链验证，后者要求连接到具有指定证书的服务器。
二者共同使用，不能删除指纹后只留下 `insecure=1`。

必须使用支持并实际执行证书指纹校验的客户端。第三方客户端可能忽略未知参数；
本项目不能替任意客户端保证导入和校验行为。
目前对官方 Hysteria 核心执行真实错误指纹拒绝测试，并检查 v2rayN 上游的导入实现；
图形客户端的实际验证范围见[验证记录](verification.md)。

## 安装边界

上游核心固定为 2.12.2；amd64 和 arm64 二进制的 SHA-256 固定在源代码中。
独立安装脚本也会校验从固定标签下载的 Python 管理工具。
HTTPS 和校验和用于确认下载与发布内容一致，不能替代对发行来源的信任。

密码与私钥不通过命令行参数传递。服务以专用非 root 用户运行，不授予额外 Linux capabilities。
配置目录为 `0750`，核心配置与私钥为 `0640 root:hy2-easy`，分享和客户端文件为 `0600 root:root`。
二维码和链接等同于连接凭据，不要公开。

参考：[上游 URI 规范](https://v2.hysteria.network/docs/developers/URI-Scheme/)、
[上游 TLS 配置](https://v2.hysteria.network/docs/advanced/Full-Client-Config/#tls)。
